# Automagy 0.28.6

Для Minecraft 1.7.10, Forge 10.13.4.1614, Thaumcraft 4.2.3.5 и Baubles 1.0.1.10. Содержит все [исправления 0.28.5](0.28.5.md).

## Исправления

| Проблема | Результат |
| --- | --- |
| Фильтр имени со множеством звёздочек вызывал экспоненциальный перебор регулярного выражения. | Промежуточные литералы фиксируются на самом раннем совпадении атомарными группами. Сохраняются маски, буквальная обработка спецсимволов и существующий интерфейс `Pattern`; перебор комбинаций исключён. |
| Осиротевшее ядро Inventarium повторно выдавало дроп кешированного чужого блока. | До работы проверяются действительность TileEntity, его регистрация и настоящий блок ядра. Дроп собственного блока выдаётся после успешного удаления один раз. Устаревший экземпляр не удаляет запись нового ядра из карты координат. |
| Контроллер шпиля принудительно использовал metadata основания при деактивации. | Проверяется настоящее основание на сохранённой высоте. Перенесённая верхняя часть не выдаёт слитки и не удаляет соседние части. Обычная деактивация возвращает девять слитков после удаления основания; отказ удаления сохраняет возможность повторить операцию. |
| Завершённое создание Hungry Maw могло выдавать результат каждый тик. | Процесс проверяет принадлежность блоку, защищён от повторного входа и завершается один раз после удаления собственного блока. Обсидиан учитывается только после успешного удаления; прогресс сохраняется. |
| Thirsty Tank начислял жидкость при неудачном удалении источника. | Для обычного источника проверяется результат удаления. Для Forge-жидкостей проверяются фактический результат drain и изменение блока, metadata либо данных TileEntity. Учитывается фактическое количество; пустая симуляция безопасно пропускается. Это также закрывает случай, когда сам `BlockFluidClassic` возвращает ведро вопреки отказу записи в мир. |
| Отменённый спаун уничтожает зависший предмет или выброшенные материалы. | При неудачной замене зависший предмет остаётся живым. Первоначальные выбросы и общие обработчики дропа передают отвергнутые предметы в сохраняемую очередь мира. Возврат из переносного крафта использует этот путь и при отключённом зависании. |
| Верстак големов доверял отрицательному индексу рецепта и неверным слотам заменителей в NBT. | При загрузке индексы нормализуются. Дополнительно проверяется индекс при обращении к рецепту; допустимые слоты сохраняются. |

Функции блоков, фильтров и крафта не отключаются.

## Отложенный дроп

Очередь `AutomagyDeferredDrops` хранится через `WorldSavedData` отдельно для каждого измерения. Сохраняются NBT предмета, положение, движение и тип зависающего предмета. Раз в секунду, в конце серверного тика, повторяется не более 32 попыток; очередь не загружает чанки принудительно. Отвергнутые попытки остаются в очереди. Защита от повторного входа исключает повторную выдачу одного элемента.

Подавленные Forge дропы во время `restoringBlockSnapshots` в очередь не попадают: их выдача после отката дублировала бы восстановленные инвентари. Перед откатом мода на старую версию дождитесь обработки отложенных предметов: прежние версии не обслуживают новую очередь.

## Проверки

Проходят **126 тестов**: 88 прежних и 38 новых. Новые проверки включают отказы и разрешения удаления, повторный вход, сохранность нового ядра, нормальную выдачу слитков и Hungry Maw, отказ настоящего Forge `BlockFluidClassic`, фактическое количество жидкости, исправление NBT, баланс обычного/частично отменённого дропа, сохранение очереди через NBT, повторную выдачу, бюджет попыток, незагруженный чанк, откат блоков и обработчик мирового тика.

Восемь проверок отдельно запущены с прежним поведением классов из коммита 0.28.5: все восемь воспроизводят ошибки. Новый класс очереди и метод обработки тика оставлены в этой сравнительной сборке только для компиляции полного набора тестов; выбранные восемь проверок метод тика не вызывают. Требуются две адаптации типов восстановленного кода к API сборки, не меняющие проверяемое поведение.

На старой версии одно сравнение проблемной маски не завершалось за пять секунд. На исправленной 500 сравнений выполняются примерно за 6 мс в данной среде. Дополнительно 4000 небольших случайных случаев сравниваются с эталонной семантикой масок. [Полный отчёт](../logs/0.28.6-validation.json) содержит сценарии, сравнительные результаты и SHA-256 JAR.

Это headless-проверки с настоящими классами мода/Minecraft/Forge и моделью мира. В новых сериях подменяются FML Loader и отправка частиц; после серии исходные значения возвращаются. Игровой сервер, плагины защиты, Witchery и Thaumic Tinkerer не запускались. Сохранение очереди проверено через NBT, без настоящего перезапуска сервера.

## Сборка

```bash
python3 tools/fetch-inputs.py
gradle test patchedJar
python3 tools/verify-release.py
```

В подготовленной среде вместо `gradle` используется `/workspace/minecraft-1.7.10/bin/mc-gradle`. Требования к JDK описаны в [0.28.4](0.28.4.md).

Результат: `build/libs/Automagy-1.7.10-0.28.6.jar`. Компилируются 25 Java-файлов; заменяются 28 исходных классов и добавляется один класс очереди. В итоговом JAR 440 классов; 411 исходных классов и все 241 ресурс побайтово сохранены. Относительно опубликованного JAR 0.28.5 изменены 12 классов, добавлен один; остальные 427 классов совпадают побайтово. Внутренний `mcmod.info` остаётся 0.28.2, версия сборки указана в имени JAR и теге.

Для установки остановите сервер, сохраните копию мира и замените прежний JAR Automagy. Одновременно должен быть установлен один Automagy. На клиенте используйте тот же JAR.
