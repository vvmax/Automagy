# Automagy 0.28.2-fixes.1

Minecraft 1.7.10, Forge 10.13.4.1614, Thaumcraft 4.2.3.5. Исправления применяются к закреплённому официальному Automagy 0.28.2.

## Исправления и последствия ошибок

| Участок | Причина и последствия | Исправление |
| --- | --- | --- |
| Avarice / Miser's Pearl | Воронка убивает `EntityItem`, сохранив старый стек; фильтр жемчужины принимал мёртвую сущность. Предмет мог попасть и в воронку, и игроку. | Проверка живой сущности и положительного стека при выборе и перед каждым переносом. Штатный подбор, NBT и лимит Miser's Pearl сохранены. |
| Жемчужина в раздатчике | Нужный раздатчику конструктор ошибочно помечен клиентским. FML удаляет его на выделенном сервере: `NoSuchMethodError`. | Убрана аннотация с конструктора, поведение раздатчика остаётся включённым. |
| Цифровые клавиши верстака | Запрет касался только щёлкнутого слота, а mode 2 адресует ещё и слот хотбара. Можно было вынуть связанную палочку. Кнопка результата дополнительно превращала любой номер хотбара в 0. | Заблокирован второй адрес только для связанного слота; остальные цифровые клавиши сохранены, номер назначения результата больше не меняется. |
| Другие клики верстака | Распределение перетаскиванием обходило запрет слота; некорректный номер слота в клике мог вызвать `IndexOutOfBoundsException`. | Связанный и отображаемый слоты исключены из распределения, связанный слот исключён из сбора двойным кликом; проверены границы индекса и допустимые внешние клики. |
| Сессия переносного верстака | Старый контейнер оставался доступным после замены палочки или фокуса; хранилище продолжало ссылаться на прежний фокус. | Контейнер привязан к исходному стеку палочки и NBT фокуса; действия после замены отклоняются. |
| Закрытие переносного верстака | Повторный вызов закрытия повторно выбрасывал неочищенные материалы. | Закрытие выполняется один раз; ячейка очищается перед выдачей. Хранилище фокуса сохраняется штатно. |
| Мир виртуального верстака | Конструктор игнорировал аргумент `world` и записывал собственное пустое поле. Рецепты, которым нужен мир, могли получить `null`. | Передан настоящий мир игрока. Конкретный игровой краш рецепта не воспроизводился; неверное поле подтверждено тестом. |
| Парящие предметы после крафта | Родительский `onUpdate` мог собрать/объединить/удалить сущность; код затем копировал её старый стек в новую сущность при окончании задержки. | После родительского обновления проверяется, жива ли сущность. |
| Грибные вёдра | Не было стандартных событий ведра/установки, проверки защиты спавна; блок менялся и на клиенте, а результат `setBlock` игнорировался. Возможен обход защиты и рассинхронизация. | Изменения только на сервере, проверки редактирования и спавна, `FillBucketEvent`, `BreakEvent` при замене растения, `PlaceEvent` с откатом при отмене/исключении. Дроп после разрешения; блоки с TileEntity не заменяются. |

Причины полного отключения фокуса в присланном архиве достоверно неизвестны. В этом релизе устраняются найденные ошибки контейнера, а фокус остаётся включённым. Полный запрет mode 2 и отключение раздатчика не перенесены. Ведро не зависит от частного `su.dreamcraft.utils.EventUtils`. Изменение текстуры фокуса и конструктор, игнорирующий бросающего, также не перенесены.

## Проверка

29 тестов проходят на исправленном коде. Из них 18 падают при тех же тестах на `199e9fb85048c60db1a79d30c0eec84118512ace`, где уже исправлен дюп жемчужины, но ещё отсутствуют остальные правки. Ошибки сравнения — проверки поведения и воспроизводимый выход за границы, а не ошибки подготовки окружения. Для первого исправления жемчужины ранее отдельно проверен исходный импорт: 5 из 8 тестов падали до исправления.

Тесты используют реальные классы предметов, инвентаря, переноса воронки и контейнера Minecraft/Forge. Мир, игроки и шина событий в соответствующих сценариях подменены Mockito. Серверный конструктор проверяется настоящим FML `SideTransformer` в режиме SERVER. Для headless JVM тесты создают минимальные записи реестров и моделируют состояние отмены события, обычно создаваемое FML-трансформером.

Проверены нормальный перенос живых предметов, частичный подбор и NBT, лимит жемчужины, допустимые цифровые клавиши, открытие GUI фокуса, сохранение количества/metadata/NBT в хранилище, разрешённая установка жидкости и отказ/откат при запрете. [Машиночитаемый отчёт](../logs/fixes-validation.json) включает результаты до/после и SHA-256 артефакта.

**Границы проверки:** игровой клиент, выделенный сервер и связка Sigmarix/Crucible с плагинами приватов не запускались. Проверены контракты Forge; фактическая защита Bukkit-привата зависит от моста событий конкретного ядра. Повторное закрытие и замена фокуса воспроизведены вызовами методов, но доступность этих последовательностей удалённому игроку в конкретной сборке не доказана. Релиз не заявляет устранение всех возможных дюпов мода.

## Сборка

Нужны Python 3, Gradle 9.2.0 (запуск на Java 17+), JDK 8 для компиляции мода и тестов, JDK 17 для remapper. Укажите JDK через `JAVA8_HOME` и `JAVA17_HOME`.

```bash
python3 tools/fetch-inputs.py
gradle test patchedJar
python3 tools/verify-release.py
```

В подготовленной среде вместо `gradle` используется `/workspace/minecraft-1.7.10/bin/mc-gradle`. Результат: `build/libs/Automagy-1.7.10-0.28.2-fixes.1.jar`. Сборка компилирует пять исправленных Java-файлов с MCP stable 12, выполняет reobfuscation в SRG и подставляет шесть классов в официальный JAR. Остальные 433 класса и 241 ресурс остаются побайтово исходными. Внутренний `mcmod.info` сохраняет 0.28.2; исправление различается по имени и SHA-256.

Для повторения сравнения подготовьте каталог с этими пятью Java-файлами из коммита `199e9fb`, затем выполните `gradle test -PpearlSourceRoot=<каталог>`. После сравнения повторите обычную сборку без свойства. Отдельное историческое [описание дюпа жемчужины](avarice-pearl-hopper-fix.md) относится к предыдущей сборке `pearl-fix.1`.

## Установка

Остановите сервер, сохраните мир и старый JAR. Замените существующий Automagy 0.28.2 файлом из релиза; одновременно в `mods` должен находиться один Automagy. Для клиента используйте тот же файл. При откате верните старый JAR; ранее созданные дубликаты это не удаляет. Иные серверные патчи поверх Automagy автоматически в релиз не входят.

Перед рабочим сервером на копии мира проверьте жемчужины с воронками и подсчётом предметов после перезапуска, раздатчик на выделенном сервере, обычный/магический крафт и хранение в фокусе, цифровые клавиши и закрытие GUI. Для вёдер проверьте разрешённую зону, запрещённый приват и границу привата, защиту спавна, замену растений, отсутствие дропа и расхода при отмене.
