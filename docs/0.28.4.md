# Automagy 0.28.4

Для Minecraft 1.7.10, Forge 10.13.4.1614, Thaumcraft 4.2.3.5 и Baubles 1.0.1.10. Содержит все [исправления 0.28.3](fixes-release.md).

## Изменения

| Проблема | Исправление |
| --- | --- |
| Пакет Inventarium изменял очередь произвольного ядра по координатам клиента. | Проверяется открытый `ContainerScribe`, доступность книги, возможность запрашивать предметы и её настоящая привязка к ядру. Получатель берётся из серверной книги; подмена координат отвергается до обращения к чужому блоку. Удалённая работа через настоящую книгу сохраняется. |
| Некорректное направление Vis Reader попадало в индекс массива и сохранялось в NBT. | Пакеты проверяются по допустимым значениям. Ранее сохранённые неверные направления, режимы и отрицательные ёмкости нормализуются при загрузке. |
| Цифровые клавиши, перетаскивание и двойной клик обходили защиту ручного зеркала. Ввод зеркала в собственный GUI оставлял предмет в брошенном контейнере. | Защищены оба адреса цифрового клика и связанный слот во всех используемых операциях. Сессия привязана к исходному стеку. Контейнер не заменяется без нормального закрытия; возврат ввода выполняется один раз. Остальные цифровые клавиши работают. |
| Буфер зеркала списывал предмет даже при `spawnEntityInWorld == false`. | Учитывается результат появления сущности. При отмене буфер сохраняется. У зеркала с несколькими получателями неудавшийся выброс сохраняется в NBT и повторяется при обновлении блока; при разрушении блока оставшийся буфер обрабатывается как обычный дроп. |
| Nether Heart создавал огонь без проверки прав. | Проверяются защита спавна и редактирование блока; вызывается Forge PlaceEvent либо MultiPlaceEvent. Отмена или исключение откатывают все захваченные изменения, включая вторичные блоки при создании портала. Дополнительные позиции также проверяются на права. Запрет не вызывает сотни повторных попыток за один поджог. |
| Удаление получателя Inventarium искало координаты среди ключей предметов. | Получатель удаляется из вложенных словарей всех предметов; пустые записи очищаются. Исчезнувшая книга больше не остаётся постоянной первой целью. |
| Количества запросов могли переполнить `int` и стать отрицательными. | Сложение в картах ограничено `Integer.MAX_VALUE`. Сетевой запрос, который превысит общий предел, отклоняется целиком, чтобы счётчики ядра и получателей не разошлись. Обычная отмена и сохранение максимального количества работают. Дополнительно исправлено изменение коллекции во время отмены заявок нескольких получателей. |
| Горячая клавиша крафта допускала слот 9 вместо диапазона хотбара 0–8. | Проверена строгая верхняя граница; работа фокуса в допустимых слотах сохранена. |

Функции не отключаются. Частные библиотеки Dreamcraft/EventHelper не требуются.

## Проверка

65 тестов проходят: 29 прежних и 36 новых. Новые проверки покрывают разрешённые запросы и отмену заявок, неподходящую/недоступную книгу, подмену ядра и получателя, выгруженное ядро, повреждённый NBT Vis Reader, безопасные настройки, операции GUI зеркала и однократный возврат, отказ/разрешение появления предметов и сохранение отказавшего выброса, переполнение и отмену нескольких получателей, границы хотбара, разрешённый/запрещённый поджог и полный откат нескольких захваченных блоков.

Используются настоящие классы мода, предметов, контейнеров и воронки Minecraft/Forge; мир, игрок и шина событий в соответствующих сценариях подменены Mockito. Сохраняется проверка реальным FML SideTransformer для SERVER. Отмена событий в headless JVM моделирует состояние, обычно обеспечиваемое трансформером FML. Вторичные изменения при поджоге моделируются как захваченные BlockSnapshot; настоящее создание портала не запускалось.

Предварительный аудит на 0.28.3 отдельно воспроизвёл ошибки девятью диагностическими проверками: [результаты аудита](../logs/audit-0.28.3-diagnostics.json). Это проверки наличия старых дефектов, а не сравнение результатов новой полной регрессионной серии. [Отчёт релиза](../logs/0.28.4-validation.json) содержит все 65 сценариев, состав JAR и SHA-256.

Клиент, игровой сервер и Sigmarix/Crucible с плагинами приватов не запускались. Реальная защита Bukkit-приватов зависит от поддержки Forge PlaceEvent/MultiPlaceEvent конкретным ядром. Перед рабочим сервером проверьте эти события на копии мира.

## Сборка и установка

Нужны Python 3, Gradle 9.2.0 на Java 17+, JDK 8 для мода/тестов и JDK 17 для remapper. Пути к JDK задаются через `JAVA8_HOME` и `JAVA17_HOME`. Baubles добавлен как закреплённая зависимость компиляции Vis Reader; входные зависимости скачиваются с проверкой SHA-256.

```bash
python3 tools/fetch-inputs.py
gradle test patchedJar
python3 tools/verify-release.py
```

В подготовленной среде используется `/workspace/minecraft-1.7.10/bin/mc-gradle`. Результат: `build/libs/Automagy-1.7.10-0.28.4.jar`.

Сборка компилирует 15 исправленных Java-файлов, переводит их в SRG и заменяет 16 классов в официальном Automagy 0.28.2. Остальные 423 класса и все 241 ресурса побайтово сохранены. Относительно 0.28.3 изменены десять классов; шесть ранее исправленных классов сохранены побайтово. Внутренний номер `mcmod.info` остаётся 0.28.2; для различения сборок используйте имя JAR и контрольную сумму.

Остановите сервер, сохраните мир и прежний JAR, замените Automagy файлом из релиза. Одновременно должен быть установлен один Automagy. Используйте тот же JAR на клиенте. Новый буфер `PendingOutput` у зеркала с несколькими получателями не понимается старыми версиями: перед откатом убедитесь, что он опустел, иначе отложенные предметы останутся недоступны старому коду.
