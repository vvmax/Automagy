# Automagy 0.28.2 — декомпилированный код для Minecraft 1.7.10

Восстановлено из официального `Automagy-1.7.10-0.28.2.jar`:
https://www.curseforge.com/minecraft/mc-mods/automagy/files/2285272

Автор мода: Tuhljin; графика: Tuhljin и Draanor, согласно исходному `mcmod.info`.

Релиз **0.28.4** закрывает подмену запросов Inventarium и краш Vis Reader, исправляет потерю предметов в зеркалах, учёт заявок и проверки защиты при использовании Nether Heart. Все исправления 0.28.3 сохранены; фокус, зеркала, раздатчик и допустимые цифровые клавиши работают. [Изменения, проверки и сборка](docs/0.28.4.md); [готовый релиз](https://github.com/vvmax/Automagy/releases/tag/v0.28.4).

## Результат

- `src/main/java/`: 409 Java-файлов, охватывающих все 439 классов JAR, включая вложенные.
- `src/main/resources/`: все 241 исходных ресурса, без изменений.
- `Automagy-1.7.10-0.28.2-sources.jar`: Java-код и ресурсы с путями от корня пакетов; можно подключить к IDE как sources.
- `Automagy-1.7.10-0.28.2-mcp.jar`: тот же байткод мода с именами членов Minecraft в пространстве MCP stable 12. Предназначен для анализа в среде разработки; для обычной игры используйте исходный релизный JAR.
- `mappings/`: MCP stable 12 для Minecraft 1.7.10 и таблица применённых имён.
- `tools/`: исходник remapper, декомпилятор, скрипты обработки и проверки.
- `logs/`: логи и отчёт проверки.
- `provenance.json`: источники и SHA-256 входных файлов, инструментов и mappings.

Репозиторий содержит `src/`, `mappings/`, `tools/`, `logs/`, README и provenance. Результирующие JAR генерируются скриптом обработки и не хранятся в Git.

Сначала байткод обработан ASM 9.8: глобально уникальные идентификаторы SRG заменены на MCP, включая ссылки на унаследованные поля и переопределённые методы. Затем выполнена декомпиляция Vineflower 1.11.1 с информацией о типах из Minecraft/Forge, Java 8 и Thaumcraft 4.2.3.5. Код Thaumcraft не включён в результат декомпиляции Automagy.

Заменено 816 различных SRG-имён. В MCP stable 12 отсутствуют расшифровки следующих 11 имён; они сохранены:

```text
field_147501_a
field_147558_l
field_147560_j
field_147561_k
field_70532_c
func_145881_a
func_147945_b
func_150108_b
func_152777_a
func_92110_g
func_94530_a
```

Строковые литералы, в том числе SRG-имена для reflection, сохранены. Их нельзя массово заменять как обычные идентификаторы.

## Проверка и ограничения

Проверено: число и состав классов; имена и дескрипторы объявлений и ссылок на члены после remap; сохранность строковых литералов; побайтовая сохранность ресурсов; наличие Java-файла для каждого верхнеуровневого класса; отсутствие маркеров ошибки декомпилятора. Все 409 файлов прошли синтаксический разбор javac в режиме Java 8 без ошибок.

Это восстановленный Java-код. Комментарии, исходное форматирование и отсутствующие в байткоде имена локальных переменных не восстанавливаются. Полная перекомпиляция всех 409 файлов и запуск в игре не выполнялись; сборка исправления компилирует 15 изменённых Java-файлов и заменяет 16 классов, включая вложенный фильтр жемчужины. Остальные 423 класса и 241 ресурс побайтово сохранены. Оригинальная конфигурация сборки в релизном JAR отсутствует. Для компиляции остальных классов потребуются Forge 1.7.10, Thaumcraft, Baubles и API интеграций, на которые ссылается код.

## Повторить обработку

Входные JAR не включены в репозиторий. Загрузите закреплённые файлы с проверкой SHA-256:

```bash
python3 tools/fetch-inputs.py
```

Нужны Python 3, JDK 17+ для инструментов, JDK 8 для информации о типах и подготовленный MCP stable 12 Minecraft 1.7.10 + Forge 10.13.4.1614 JAR. Инструменты Vineflower и ASM включены в `tools/`.

Пример для текущего окружения:

```bash
python3 tools/decompile.py \
  --minecraft-jar /workspace/minecraft-1.7.10/examples/forge-mod/build/rfg/recompiled_minecraft-1.7.10.jar \
  --runtime /workspace/minecraft-1.7.10/tools/jdk8 \
  --java /workspace/minecraft-1.7.10/tools/jdk17/bin/java \
  --javac /workspace/minecraft-1.7.10/tools/jdk17/bin/javac
python3 tools/verify.py
```

Декомпиляция перезаписывает сгенерированные файлы в `src/`; перед повторным запуском сохраните собственные изменения.
